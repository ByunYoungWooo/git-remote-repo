# 🏢 **출퇴근 관리 자동화 시스템 기획서**

## 📋 **프로젝트 개요**

| 항목 | 내용 |
|------|------|
| **프로젝트명** | `소기업 출석관리 Pro` (가칭) |
| **버전** | v1.0.0 |
| **개발 기간** | 2~4 주 |
| **목표 사용자** | 100 명 미만 소기업 직원/팀장/HR |

### **🎯 핵심 목표:**
```
소형 기업에서 효율적인 출퇴근 관리 자동화 시스템을 구축하여,
- 직원들의 출퇴근 시간 투명성 확보
- 연차/대휴 관리 용이성 증대
- 공휴일 캘린더 기반 직관적 인터페이스 제공
- 관리자용 어드민 페이지로 세부 제어 가능
```

## 📊 **핵심 기능 요구사항**

### **1. 기본 기능 (MUST-HAVE)**

#### **① 출퇴근 시간 체크**
- ✅ **자동 체크**: GPS/Wi-Fi 기반 자동 출퇴근打卡
- ✅ **수동 체크**: 웹에서 직접 기록 입력 (비정상 출퇴근 시)
- ✅ **지각/조기퇴근 감지**: 기준시간 대비 초과분 자동 계산
- ✅ **정산 데이터 출력**: 월별 정산용 엑셀 파일 내보내기

#### **② 연차/대휴 관리**
- ✅ **연차 신청**: 웹에서 날짜 선택 → 팀장 승인 요청
- ✅ **승인 워크플로우**: 팀장이 어드민 페이지에서 승인/거부
- ✅ **잔여 연차 조회**: 실시간 잔여 연차량 표시
- ✅ **대휴 캘린더**: 공휴일 + 대휴 일자 통합 캘린더 (달력 인터페이스)

#### **③ 웹 기반 UI (모바일 대응)**
- ✅ **반응형 디자인**: PC/모바일 모두 최적화
- ✅ **공휴일 포함 달력**: 월별/년별 캘린더, 공휴일 자동 표시
- ✅ **간편 인터페이스**: 3 클릭 이내 출퇴근 체크 완료

#### **④ 통계 분석**
- ✅ **출퇴근 패턴**: 평일 평균 출퇴근 시간, 지각 빈도 등
- ✅ **연차 통계**: 연차 사용률, 잔여량, 팀별 비교
- ✅ **대휴/공휴일**: 공휴일 포함 휴가 기간 분석

### **2. 선택 기능 (NICE-TO-HAVE)**

#### **⑤ 알림 시스템**

## 🗄️ **데이터베이스 설계**

### **테이블 구조:**

#### **1. 직원 정보 테이블 (`employees`)**
```sql
CREATE TABLE employees (
    id INT AUTO_INCREMENT PRIMARY KEY,
    employee_id VARCHAR(20) UNIQUE NOT NULL,  -- 회사부서 번호
    name VARCHAR(100) NOT NULL,               -- 이름
    department VARCHAR(50),                    -- 부서
    position VARCHAR(50),                      -- 직급
    email VARCHAR(255) UNIQUE,
    phone VARCHAR(20),                         -- 전화번호 (SMS 발송용)
    attendance_time_in TIME DEFAULT '09:00:00', -- 기본 출근시간
    attendance_time_out TIME DEFAULT '18:00:00',-- 기본 퇴근시간
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

#### **2. 출석 기록 테이블 (`attendance_logs`)**
```sql
CREATE TABLE attendance_logs (
    id INT AUTO_INCREMENT PRIMARY KEY,
    employee_id VARCHAR(20) NOT NULL,         -- 직원 ID
    check_date DATE NOT NULL,                 -- 체크 날짜
    time_in TIME,                             -- 실제 출근시간
    time_out TIME,                            -- 실제 퇴근시간
    status ENUM('present', 'late', 'absent', 'early_leave') DEFAULT 'present',
    reason TEXT,                              -- 지각/결석 사유
    auto_checked BOOLEAN DEFAULT TRUE,         -- 자동 체크 여부
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (employee_id) REFERENCES employees(employee_id)
        ON UPDATE CASCADE ON DELETE RESTRICT
);
```

#### **3. 연차 관리 테이블 (`leaves`)**
```sql
CREATE TABLE leaves (
    id INT AUTO_INCREMENT PRIMARY KEY,
    employee_id VARCHAR(20) NOT NULL,         -- 직원 ID
    leave_type ENUM('annual', 'sick', 'paid_off') DEFAULT 'annual',  -- 연차/병가/유급휴가
    start_date DATE NOT NULL,                 -- 시작일
    end_date DATE NOT NULL,                    -- 종료일
    duration_days INT NOT NULL,               -- 기간 (일)
    status ENUM('pending', 'approved', 'rejected') DEFAULT 'pending',
    applied_by VARCHAR(50),                   -- 신청자 이름
    approved_by VARCHAR(50),                  -- 승인자 이름
    approved_at TIMESTAMP,                     -- 승인 시간
    FOREIGN KEY (employee_id) REFERENCES employees(employee_id)
        ON UPDATE CASCADE ON DELETE RESTRICT
);
```

#### **4. 공휴일/대휴 캘린더 테이블 (`holidays`)**
```sql
CREATE TABLE holidays (
    id INT AUTO_INCREMENT PRIMARY KEY,
    holiday_name VARCHAR(100) NOT NULL,         -- 휴가명칭 (설날, 추석 등)
    date DATE NOT NULL,                        -- 날짜
    year YEAR NOT NULL,                        -- 년도 (중복 방지용)
    type ENUM('public_holiday', 'paid_off', 'special') DEFAULT 'public_holiday',  -- 공휴일/유급대휴/특수
    is_weekend BOOLEAN DEFAULT FALSE,          -- 주말과 중복 여부
    UNIQUE KEY unique_holiday (year, date)     -- 년도별 중복 방지
);
```
