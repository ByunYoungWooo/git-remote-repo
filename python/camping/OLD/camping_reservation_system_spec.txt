# 🏕️ **캠핑장 예약 자동화 시스템 기획서** (Python Edition)

## 📋 **프로젝트 개요**

| 항목 | 내용 |
|------|------|
| **프로젝트명** | ` 캠핑장 예약 관리 Pro ` (가칭) |
| **버전** | v2.0.0 (PHP → Python 전환 버전, 이전 PHP 기획서는 `camping_reservation_system_spec_php_v1.txt`) |

| **목표 사용자** | 캠핑장 운영자/예약자/직원 |

### **🎯 핵심 목표:**
```
소규모 캠핑장에서 효율적인 예약 자동화 시스템을 구축하여,
- 예약 처리 시간 단축 (24 시간 이내 응답)
- 공간 활용도 극대화 (일정 기반 최적 배치)
- 고객 만족도 향상 (자동 알림/예약 관리)
- 운영 효율성 증대 (자동 정산/보고서 생성)
```

## 💻 **기술 스택 결정 (Python)**

| 계층 | 기술 | 설명 |
|------|------|------|
| **프론트엔드** | HTML + CSS + JavaScript | Bootstrap 5 반응형 UI, Jinja2 템플릿 |
| **백엔드** | Python 3.12 + FastAPI | async REST API + 웹페이지 렌더링, OpenAPI 자동 문서 |
| **ORM/데이터베이스** | SQLAlchemy 2.0 + PyMySQL → MariaDB | 타입hints 기반 ORM, 마이그레이션은 Alembic (또는 schema.sql 유지) |
| **알림 시스템** | Telegram Bot API (`httpx` async 호출) | 다중 채널 확장 구조 (Nodemailer 계열 → `aiosmtplib` 가능) |
| **배치 작업** | APScheduler | 데일리 알림, 잔여일수 체크 자동 실행 |
| **서버** | uvicorn (개발) / gunicorn+uvicorn workers (운영), systemd 관리 | Apache/PHP-FPM 불필요 |
| **호스팅** | VPS (Ubuntu 22.04 LTS) + Nginx 리버스프록시 | Docker 컨테이너화 선택 가능 |

### **추천 스택 이유:**
- ✅ **FastAPI**: 타입 검증(pydantic v2) 내장 → 입력 오류/SQL 인젝션 표면 최소화, `/docs`로 API 문서 자동
- ✅ **SQLAlchemy 2.0**: 파라미터화된 쿼리만 생성 (raw SQL 거의 불필요), async 지원
- ✅ **Jinja2 + Bootstrap 5**: 기존 attendance 프로젝트와 동일한 UI 스타일 유지 → 학습/유지보수 비용 절감
- ✅ **APScheduler**: 알림 잡을 별도 크론 없이 코드에서 관리, 프로세스 내 스케줄링
- ✅ **Telegram Bot API**: 무료 알림 채널 (기존 `config.py`에 토큰 구조 이미 존재)

## 🔐 **보안 고려사항**

1. ✅ **HTTPS 사용**: Let's Encrypt 무료 SSL 인증서 적용 (Nginx 터미네이션)
2. ✅ **CSRF 보호**: 서버 렌더 폼에 토큰 추가 (FastAPI 미들웨어 또는 Jinja 헬퍼)
3. ✅ **SQL Injection 방지**: SQLAlchemy ORM/파라미터 바인딩만 사용 (raw SQL 금지 원칙)
4. ✅ **XSS 방어**: Jinja2 자동 이스케이프 + 출력 검증 (pydantic)
5. ✅ **세션 관리**: 30 분 비활성시 자동 로그아웃, `HttpOnly+Secure` 쿠키
6. ✅ **접속 로그**: 관리자 페이지 모든 접근 기록 (middleware logging)
7. ✅ **비밀정보 관리**: `.env` + gitignore, 코드에 비밀번호 하드코딩 금지
8. ✅ **결제 보안**: PCI-DSS 범위 최소화 — v1은 가상 결제/입금확인, 실제 PG 연동 시 토큰화 카드 정보만 처리
